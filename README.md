# 🎬 AutoScriptor — AI Video Script Cloner & Shorts Generator

**AutoScriptor** — инструмент для контент-мейкеров, ютуберов и авторов Shorts/Reels/TikTok. Анализирует структуру и темп любого успешного видео на YouTube, переписывает его сценарий своими словами, генерирует естественную **нейроозвучку** и собирает **готовое вертикальное видео 9:16 с виральными субтитрами**!

---

## ✨ Что делает AutoScriptor:

1. 🔥 **3 виральных варианта заголовка** для видео;
2. ⚡ **Мощный хук** для первых 3 секунд, удерживающий зрителя;
3. 📜 **Готовый сценарий для озвучки** (динамичные, короткие абзацы);
4. 🎙 **Студийная нейроозвучка (Edge-TTS)**: русские голоса *Дмитрий* и *Светлана* с настройкой темпа речи (+10%, +20%);
5. 🎬 **Монтаж Shorts 9:16 (FFmpeg)**: вертикальный формат, стильные динамичные субтитры по центру (как в CapCut/TikTok), сведение аудио и видео;
6. 📥 **Встроенные плееры и экспорт**: предпросмотр видео прямо в браузере и скачивание готового `.mp4`;
7. 📌 **SEO-описание и хэштеги** для быстрой публикации.

---

## 🚀 Два режима работы

### Режим 1: Локальный запуск (Полный функционал: Сценарий + Голос + Видео)
Для генерации `.mp3` аудиодорожки и рендеринга `.mp4` видеороликов через ваш локальный FFmpeg:

1. Запустите файл **`run.bat`** (или выполните команду `python server.py`).
   * *Скрипт автоматически проверит и установит `edge-tts` при необходимости.*
2. В браузере откроется **`http://localhost:8000`**.
3. Вставьте ссылку на YouTube видео/Shorts и нажмите «Сгенерировать контент».
4. В блоке сценария нажмите:
   * **🎙 Сгенерировать голос** — прослушайте естественную нейроозвучку.
   * **🎬 Собрать видео (Shorts 9:16)** — через пару секунд появится плеер с готовым роликом и кнопка **Скачать MP4**!
